# Hollow の初期アイデア

## 目的

Hollow は、さまざまな形式のファイルを読みやすい HTML に変換し、保存・編集・整理・共有できるサービスである。個人の資料置き場と、チームで文書を扱うワークスペースを同じ操作体系で提供する。

## 想定する利用者

- PDF、Office 文書、画像、音声などをブラウザーで読める形にまとめたい個人
- 変換した文書を限定公開または公開で共有したい利用者
- 共通の資料をメンバーで整理・閲覧・編集したいチーム

## 中心となる体験

- ファイルをアップロードすると、内容が HTML のノートに変換される
- 機械的な抽出で足りない形式は、利用者自身の OpenRouter 連携を使って構造化する
- 変換したノートを編集し、タグ・検索・月・表示形式で整理する
- ノートを非公開、限定公開、公開から選んで共有する
- 個人とワークスペースを切り替えながら、同じ方法でノートを扱う
- 元ファイルを Google Drive にバックアップし、必要に応じて再生成する

## 対応する入力

- HTML
- Markdown
- Word、Excel、PowerPoint、プレーンテキスト
- テキストを含む PDF と画像化された PDF
- 画像
- 音声

HTML と Markdown は機械的に変換する。文書、PDF、画像、音声は抽出可能な内容を機械的に取り出し、OpenRouter 連携がある場合は LLM で構造化する。音声認識が必要な入力も利用者の連携先を使う。

## 編集と整理

- HTML を正データとして保存する
- レンダリング結果のテキストを直接編集するモード、HTML 編集、WYSIWYG 編集を提供する
- 白紙のノートを作成できる
- 画像と動画を本文へ追加できる
- タグ付け、全文検索、月による絞り込みを提供する
- 一覧はタイル、リスト、カレンダーで表示できる

## 共有

- 新しいノートは非公開にする
- 限定公開は共有リンクを知る人だけが閲覧でき、パスワードを設定できる
- 公開ノートは利用者またはワークスペースの公開ページと公開検索に表示し、検索エンジンによる発見を許可する
- 個別または複数のノートを HTML、Markdown、PDF でダウンロードできる

## アカウントと連携

- Google SSO とメールアドレス・パスワード認証を提供する
- 1 人の利用者に複数の認証手段を紐づけられる
- OpenRouter は OAuth PKCE で連携し、利用者自身のアカウントと利用料を使う
- Google Drive は Google 認証後の追加同意で連携する

## ワークスペース

- ノートは個人または 1 つのワークスペースに所属し、後から移動できる
- ワークスペースのロールは owner、editor、viewer とする
- owner は設定、公開、メンバー管理、削除、ノート操作を行える
- editor はノートの作成、編集、削除、公開設定を行える
- viewer はノートを閲覧・ダウンロードできる
- ワークスペースは公開ページを持ち、公開ノートだけを掲載する

## 前提

- UI は日本語で提供する
- 課金とプラン管理は対象外とする
- 重い変換、バックアップ、一括処理、書き出しは非同期で実行し、進捗を表示する
- ファイルサイズや利用回数などの上限を設ける
- 実行基盤、永続化方式、検索基盤、ジョブ基盤は技術設計で決める
