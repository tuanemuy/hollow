# 書き出し（EX）

ノートを HTML / Markdown でダウンロードし、ブラウザーで印刷（PDF として保存）するシナリオ。

## EX-01: ノートを 1 件ダウンロード・印刷する

**利用者**: 所有者 / メンバー
**事前条件**: 対象ノートを閲覧できる

### 基本フロー

1. ノート詳細のメニューから「ダウンロード」を選び、形式（HTML / Markdown）を選ぶ
2. HTML と Markdown は即座に生成されてダウンロードが始まる
3. 印刷するときは「印刷」を選ぶ。新しいタブに印刷用の表示が開き、画像の読み込みを待ってブラウザーの印刷が始まる
4. PDF が欲しい場合は、ブラウザーの印刷の送信先で「PDF に保存」を選ぶ

### 異常系・エッジケース

- HTML はスタイルと画像を埋め込んだ 1 ファイルとして出力する。埋め込めなかった参照は元の URL のまま残す
- Markdown は HTML から機械的に変換する。表現できない要素は HTML のまま残す
- 本文が空（変換処理中 / 要 LLM 連携）のノートはダウンロードも印刷もできない
- ファイル名はタイトルから生成し、使えない文字は置き換える。空になる場合はノートの識別子を使う
- 印刷用の表示は保存済みの本文を、閲覧画面と同じ表示スタイル・同じ画像の許可範囲で 1 枚のページに載せる。画面の操作部分は印刷されない。文書名はノートのタイトルで、ブラウザーの「PDF に保存」の既定のファイル名になる
- 読み込めない画像があっても、一定時間（15 秒）待ったところで印刷を始める。印刷を取り消しても、印刷用の表示の「印刷する」から何度でもやり直せる
- 用紙サイズ・余白・ヘッダーとフッターはブラウザーの印刷設定に従う
- 閲覧画面をそのままブラウザーで印刷した場合は、印刷用の表示から印刷するよう促す一文だけが印刷される

## EX-02: 複数のノートを一括ダウンロードする

**利用者**: 所有者 / メンバー
**事前条件**: 対象ノートを閲覧できる

### 基本フロー

1. 一覧で複数のノートを選び、操作バーから「ダウンロード」を選ぶ（OR-09）
2. 形式（HTML / Markdown）を選び、実行する
3. ZIP を生成するジョブが登録され、進捗が表示される
4. 完了すると通知が表示され、ダウンロードできる

### 異常系・エッジケース

- 件数の上限（500 件）または合計サイズの上限（1 GB）を超える場合、分割を促す
- ダウンロードできないノート（本文が空）は対象から除外し、件数を示す
- 一部のノートの生成に失敗した場合、成功分を含む ZIP を提供し、失敗した対象の一覧を同梱する
- ファイル名が重複する場合は連番を付けて衝突を避ける
- 絞り込み結果全体を対象とする「全選択」でも同じ上限が適用される
- 実行中に対象ノートが削除された場合、そのノートは除外して継続する

## EX-03: 一括ダウンロードの生成状況を確認して受け取る

**利用者**: 一括ダウンロードを実行した利用者
**事前条件**: EX-02 を実行している

### 基本フロー

1. 画面を離れても生成は継続し、処理ティッカーに進行中として表示される
2. 処理履歴（JB-01）から状況を確認できる
3. 完了すると通知が表示され、履歴からダウンロードできる
4. 生成物は一定期間（7 日）保持され、その間は何度でもダウンロードできる

### 異常系・エッジケース

- 生成に失敗した場合、理由と再実行の導線を示す
- 保持期間を過ぎた生成物は削除され、履歴には期限切れとして表示される
- 生成中にキャンセルできる。キャンセルすると中間生成物は破棄される
- 同時に実行できる一括ダウンロードは 1 件までとし、実行中は新たな要求を受け付けない。既に実行中である旨を示し、完了後に再実行するよう案内する（待機列は設けない）

## EX-04: 閲覧者がノートをダウンロード・印刷する

**利用者**: 閲覧者（サインイン不要）
**事前条件**: 公開ノート、または有効な共有リンク（必要ならパスワード通過済み）

### 基本フロー

1. 公開ページまたは共有リンクの画面で「ダウンロード」を選び、形式（HTML / Markdown）を選ぶ
2. EX-01 と同じ手順でダウンロードされる
3. 印刷するときは「印刷」を選ぶ。EX-01 と同じ印刷用の表示が開き、ブラウザーの印刷が始まる

### 異常系・エッジケース

- 閲覧できるノートは常にダウンロード・印刷できる（閲覧のみを許す設定は設けない）
- ダウンロード操作にレート制限をかける。印刷用の表示はノートの閲覧と同じ扱いで、レート制限をかけない
- ダウンロードと印刷用の表示を開くたびに閲覧の可否を確認し直す。閲覧中にノートが非公開に戻された・削除された・共有リンクが再発行された場合、「見つかりません」で失敗する。公開のままゴミ箱に入った公開ノートは公開ページと同じく「削除済み」になる
- パスワードを通過していないブラウザーで共有リンクの印刷用の表示を開いた場合、共有リンクの画面（パスワード入力）へ戻す
- 公開ノートの印刷用の表示は検索エンジンに載せない
- 一括ダウンロードは閲覧者には提供しない
