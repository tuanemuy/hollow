# Hollow 要件

## プロダクト要件

- 利用者は対応ファイルを 1 件または複数件アップロードし、HTML のノートへ変換できる
- 変換方法は入力形式と利用可能な外部連携から決まり、処理中・成功・要連携・失敗を確認できる
- 外部参照を取得できる場合は Hollow 内へ保存し、ノートの参照先を差し替えられる
- 利用者はノートを作成・閲覧・編集・削除・復元・完全削除できる
- 利用者はノートをタグ、全文検索、月、並び順で整理できる
- 利用者はノートの所属先を個人とワークスペースの間で移動できる
- 利用者はノートを非公開、限定公開、公開に設定できる
- 利用者はノートを個別または一括で書き出せる
- 利用者は処理履歴を確認し、失敗した処理の再試行と実行中の処理のキャンセルを行える

## アカウント要件

- メールアドレス・パスワードと Google で登録・認証できる
- メール確認、パスワード再設定、認証手段の追加・解除を行える
- プロフィールと公開ハンドルを編集できる
- アカウントと関連データを削除できる
- 外部連携と使用量を確認できる

## 連携要件

- OpenRouter と OAuth PKCE で連携し、変換に使うモデルを選択できる
- OpenRouter の API キーを Hollow に直接入力する方式は提供しない
- Google Drive と追加同意で連携し、元ファイルをバックアップできる
- バックアップした元ファイルからノートを再生成できる
- 外部連携は利用者単位で管理し、解除できる

## ワークスペース要件

- 利用者はワークスペースを作成し、招待を通じて参加できる
- owner、editor、viewer のロールで操作範囲を制御する
- メンバーの招待、ロール変更、除名、脱退を行える
- ワークスペースを公開または非公開にできる
- 公開ワークスペースには公開ノートだけを表示する
- ワークスペースを削除できる

## 体験要件

- 個人とワークスペースの現在位置を常に判別できる
- 変換状態と公開範囲を一覧と詳細の両方で判別できる
- キーボードとポインティングデバイスのどちらでも主要操作へ到達できる
- コマンドパレット以外にも、すべての機能への視覚的な導線を用意する
- 読む画面では本文を主役にし、操作を本文から分離する
- モバイル幅でも横方向にページ全体がはみ出さない

## 非機能要件

- 公開を取り下げたノートや無効な共有リンクから、過去の存在や現在の状態を推測できない
- アップロードした HTML と生成した HTML は、アプリの UI へ影響しない境界で表示する
- 長時間処理は非同期で実行し、利用者が進捗と結果を追跡できる
- UI は日本語で提供する
- 課金とプラン管理は対象外とする

## スコープ外

- 技術アーキテクチャ、データモデル、永続化方式の決定
- 特定クラウドへのデプロイ構成
- 課金、プラン、決済
- 日本語以外の UI
