# 認証と外部連携

パスワードは安全なハッシュとして保存し、セッションは期限つきのランダムトークンと HttpOnly cookie を使う。未確認ユーザーにはセッションを発行しない。メール確認は一回限りの期限つきリンクと要求ブラウザーの識別を組み合わせる。

開発時のメールは明示的なローカル mailbox アダプターで検証し、本番向けメール送信ポートを用意する。mailbox の確認を実メール送信の合格とは扱わない。秘密や確認トークンを一般の画面へ返さない。

Google は認証と Drive の増分認可を分ける。OpenRouter は OAuth PKCE のみとし、API キーを UI から直接入力させない。資格情報の保護とローカル契約検証を実装したうえで、実接続は利用者の設定と同意で検証する。
