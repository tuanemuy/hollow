# P3cの一覧と読書UI

[UI接続案](../phases/P3c-ui-plan.md)の既存notes RSC/Suspense→ScopedNotesBoardを拡張し、追加pageとtrashの親所有を維持する。全条件をURL/request identityに含め、user別の版付き端末preferenceはview/通常sort/zoneの未指定値だけを補う。storage拒否でもURLと現在操作は成立させる。スクロールsentinelと同じ次page操作へkeyboard用button/再試行を接続し、全pageを先読みしない。単一paletteは現在認可済scopeを表示し、未確定入力と一覧確定条件を分け、既存の未保存離脱blockerを通す。

サムネイルは現在本文の構造projectionから有限の先頭text/媒体位置を作り、trusted previewとして表示する。textはReact text、画像は現在noteの正確なasset参照と認可を通す。任意CSSのraster縮小再現は保証せず、data/SVG等の安全な画像表示が未提供の媒体は種別ラベルで表す。無順序に選んだ画像を本文先頭と呼ばず、外部URL/CSSの追加取得、親DOMへのraw属性/style挿入、thumbnail用の新storage quotaを設けない。

読書用の見出し補助は本文直前の折りたたみに置く。trusted親コードが現在iframe documentの見出しtext/階層を取得し、当該document/generationのElement参照をprivateに保持して移動する。利用者id/nameを選択先の正本にせず、重複id・反復名・旧load/旧clickを混同しない。正本HTML/idを書き換えず、allow-scriptsやpostMessageを追加しない。共通NoteContentの既存sandbox/CSPとstyle previewを維持し、再取得時に旧参照を破棄する。実frame内外の移動と位置のない見出しの扱いは本体実装で確認する。

creatorは現在note認可後の表示可能な属性を投影し、記録不明をowner/uploaderで補わない。公開表示名が未提供の間、email代替表示は本人または現在同WS memberに限定する。既知creatorに表示可能属性がない状態は「表示情報なし」とし、記録unknownや退会済みと混同しない。後続の公開表示名を元memberという理由だけで恒久的に非表示にしない。原本の名前/形式/bytesとHollow保存を表示し、Driveバックアップ正本のない段階を完了・失敗・未連携と推定しない。P3cの表示は未提供を明記し、実状態と操作の完成はP5へ残す。詳細の既存取得方式を一律変更せず、本文skeletonと変換完了時の更新を維持する。
