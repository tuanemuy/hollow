# P2a の共有契約

[実形式spike](../phases/P2a-A.md)の結果から、MarkdownはMarked、DOCXはMammoth、XLSXはExcelJS、PPTXはyauzlとfast-xml-parser、PDFはPDF.jsを採用する。Nodeの宣言下限を22.13へ合わせる。fixture生成用writerはproduction依存へ入れない。spikeのコードは資源制限・型・エラー・ポートを本体へ合わせて取り込み、未検証のままコピーして完成としない。

アップロードはファイルごとのstream境界でサイズを制限し、私有stagingに保存する。確定object・容量・note・job・outboxを整合させる。ファイル名を保存パスにせず、原本は認可付きで取得する。P1で作った手書きノートは元ファイルなしの正常状態として保持し、変換中のノートだけ編集を制限する。P2aは個人・非公開の初期経路を接続し、公開希望のUIは公開機能とともにP4で追加する。

変換状態は処理中・完了・要AI連携・失敗・取消を区別する。jobはqueued/running/succeeded/failed/cancelledを保持し、failureだけが失敗理由を持つ。通知とjob履歴は実行者だけが読める。取消しても受理済みの原本・noteは残す。

HTMLとMarkdownは機械変換のみ。Officeと文字PDFは機械抽出してHTML escapeし、サニタイズ境界へ渡す。元layoutの完全再現は求めない。Excelの結合従属cellは重複出力せず、数式を実行しない。cached値がなければ式と計算結果なしを示す。PPTXはslide順・表に加え、取得可能なchart cache・SmartArt文字・notesの本文を抽出する。未対応/未読partを検出した場合は場所と内容種別を取り込み結果へ残す。

PPTXのrun間にある空白だけの文字列、改行、段落の境界を保持する。XMLのtext値を一律trimしてから連結しない。書式ごとに分かれた単語が結合する回帰を、実形式と期待文字列で検証する。

抽出した本文と内容の網羅性は別に記録する。テキスト層と画像ページが混在するPDFでは、取得したテキストを表示し、文字を抽出していないページを具体的に示す。テキスト層ありのPDFを機械変換できるという原文を維持し、画像ページが一つあることだけを理由に全文を要連携へ変更しない。本文のない正常PDF・画像・音声は原文どおり要AI連携とし、明示的なAI不使用なら失敗にする。破損・暗号化・資源超過を空本文の成功へ変換しない。

part/page/cell単位の抽出noticeを原本に属する恒久情報として保持する。job履歴の90日削除後も取り込み結果を読めるようにする。抽出文字の整形だけでは未取得内容のnoticeを消さない。本文外の装飾差と内容欠落は区別する。

parserはrequestのevent loopから分離し、deadlineで停止できるworker/child processに置く。ZIPの件数・宣言値と実展開量・必要XMLサイズ/深度・XML外部entity・任意ネットワークへのアクセスを境界で制限する。file内容を優先して形式を判定し、一般ZIPや旧OfficeをOOXML成功と誤認しない。

Jobのclaim/heartbeat/結果commitはleaseTokenで条件付ける。実行者権限とnoteの現状態をcommit時に確認し、取消・古いlease・次の試行が結果に負けないようにする。親jobは子の内訳を表示し、通常取消はqueued子のみ取り消してrunning子の完了を待つ。retryは新jobを作り重複を抑止し、親を必要に応じて再び処理中へ戻す。P2aでは変換jobを対象とし、再生成の旧本文保持・権限失効等は同じ契約を後続で拡張する。
