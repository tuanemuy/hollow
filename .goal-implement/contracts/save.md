# P2c 以降の保存契約

版は現在版を含む直近20版とし、復元も新しいversionの保存にする。本文・タイトル・表示styleの意味のある保存と、参照workerによる本文更新を同じ版契約へ接続する。既存ノートも最初の破壊的なWYSIWYG保存前の本文へ戻せるようにする。タイトル編集の既存合格根拠は保持し、版と一覧・後続共有ページの反映を追加で確認する。

ビジュアル編集ではセッション内ASTの空Textを保持し、全消去後の再入力とundoで構造・属性を変えない。HTML保存・再読込を跨ぐ内部nodeIdの永続化やbyte完全一致は要件へ追加しない。保存後の要素・属性・装飾、空本文とvisual選択可否の一貫性を検証する。
