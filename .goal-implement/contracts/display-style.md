# P2b-D の表示設定

[接続提案](../phases/P2b-D-P2c-proposal.md)の初回結果による判定を採用する。表示値はdefault/original、由来はautomatic/user/legacyを区別する。新規白紙はdefault。新規取込は安全化後に残る宣言を判定し、初回onのstylesheet取得がある場合だけ、その初回jobの終端まで判定待ちにする。待機中はdefaultの仮表示と確認中の案内を出す。

初回の部分成功・失敗・上限・取消は、実際に残る安全な装飾で一度だけ確定する。offは変換結果で確定し、後のon/retry/編集では自動変更しない。待機中の手動選択は直ちにuserとして確定する。初回jobが通常編集で置き換わる場合は記録済み初回安全本文の判定で終端化し、後続jobや編集後本文を初回と扱わない。claim上限・復旧でも永久に判定待ちを残さない。

終端済みまたは消失した初回jobの判定待ちは、永続化した初回関係・現在note/state・現在権限を確認するbounded sweepで解消する。実行中/新lease/手動選択を変更せず、失効中は据え置き、権限回復後に終端化する。本文結果や取得objectを採用するguardを代替しない。

既存noteはdefault/legacyへ移行して現在の表示を維持し、自動判定済みとは表示しない。本文/title/version/assetを移行で変更せず、既存進行中jobへ初回判定を後付けしない。

設定変更は最新本文を保持する専用commandにし、古い本文やstyleを相互に上書きしない。preview/取消/適用のpendingと失敗rollbackを提供する。originalでは既定装飾だけを外し、本文CSS・sandbox・CSP・リンク制限・現在asset認可は維持する。style変更でもworkerのversion条件を緩めず、必要な新jobへ引き継ぐ。共有/public/export本体への接続は後続フェーズで確認する。
