# HTML と編集

HTML を正データにする。保存境界のサニタイズと sandbox iframe を採用する。既存の画面案は Shadow DOM だが、iframe により本文 CSS と危険なコンテンツの隔離を強める。元の装飾とユーザーが選んだ既定スタイルは iframe 内で扱う。公開ページのメタデータと検索対象のテキストはサーバーで生成する。

新規作成は WYSIWYG。既存編集ではビジュアル・HTML・WYSIWYG を切り替える。ビジュアルはテキストノードだけを変更し構造と属性を保持する。HTML はプレビューとサニタイズ結果を示す。WYSIWYG の正規化では警告・版保持・復元を提供する。自動保存、未保存退避、競合解決、権限喪失時の内容取り出しは共通の編集責務とする。

外部リソース取得は専用アダプターが担当し、DNS 解決・リダイレクトを含め内部ネットワークへの取得を防ぐ。本文の URL は検証してから取得する。
