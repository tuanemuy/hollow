# UI

[既存画面案](../../spec/design/index.md)と [tokens](../../spec/design/tokens.md)を採用する。白・無彩色、中央一列、常設サイドバーなし。認証・アプリ・公開の三つのシェルを持つ。現在のスコープ、変換状態、公開範囲は文字で表示する。

読む画面は本文を中心にし操作を下端バーに置く。スコープメニューとアカウントメニューに視覚的な導線を置き、コマンドパレットを近道として提供する。読み込みは streaming skeleton、変更は React 19 の pending / optimistic UI と invalidate で応答する。空・通信失敗・権限失効・要連携・処理失敗を操作可能な状態として用意する。
