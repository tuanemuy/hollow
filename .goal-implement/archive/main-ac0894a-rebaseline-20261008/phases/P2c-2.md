`application/note/editorText.ts` は純粋な CRLF/CR 表示 offset と検証済み source span の escape splice を持つ。解析は Worker 内。親は最新全 Text 値から完全な退避 HTML を直ちに作るため、未応答 patch を「古い解析」として捨てない。worker 側で generation / ID / before / 重複 / 容量を再検査する。重い解析、DNS、storage I/O は UoW 内へ移していない。

共有 `application/asset/references.ts` の `renderNote` は現在認可済みのsafe canonicalをDTOへ追加し、参照準備が要素を除去する前のsanitizer noticeを最終noticeへ合流する。これがP1-C/P2b-Cのpreview共有変更。保存・current asset/履歴scopeの認可をsidecarやclient canonicalで代替しない。

CRLF/CR は表示 LF に対応づける。無編集・表示同値 input・取消は元 raw を維持する。実変更 Text は LF と既知の pre 先頭 prefix を使い、他 Text・属性・構造・raw entity は変更しない。parse5 が pre 先頭 entity の location を短くする場合は、既知 parent startTag と literal CRLF/CR/LF prefix の範囲だけを補正する。文字列を別位置で探索する fallback、DOM 全 serialize、全 HTML5 正規化はない。

子 iframe は `allow-same-origin` 単独、script 禁止・既存 CSP/current asset 認可・inert link を維持する。未信頼 HTML/CSS を親へ入れず、親 textarea の font family/size/line-height だけを既知 CSSOM property として読む。HTML + plain paste は plain だけを一回挿入し、HTML-only/file は説明付き拒否。script/style は編集対象外。空 Text は同 session の一覧から再選択でき、自己 save 応答後も ID/undo を維持する。

初期 visual の解析失敗は理由と raw/退避を保持する。実 DOM 不一致は編集停止。自己 save と異なる構造または表示 style が到着した場合は入力を消さず明示再初期化へ誘導する。新 Worker 再初期化前に旧 generation を無効化し、遅い reject が新 session を失敗へ戻さない。自己生成 HTML の識別は直近 4 snapshot に制限する。

## 運用上限

原要件と運用上限を区別する。800 × 1024 bytes は既存本文境界。その他は解析・UI の有限な運用境界であり全入力保証ではない。

| 境界 | 値 / 動作 |
| --- | --- |
| raw 本文 | UTF-8 800 KiB。超過は全文を保持して拒否し、切り詰めない |
| DOM / 深さ | 10,000 nodes / depth 128。完成 HTML5 document の wrapper 分のみ別に扱う |
| Text 対応照合 | 2,000,000 比較。曖昧・超過は説明付き停止 |
| 診断 / projection・patch | Worker 1秒 / 2秒の実 deadline。timeout は terminate、入力保持、再試行 |
| 認可 render / preview 準備 | 10秒。遅い応答の適用を止め、raw と退避を保持 |
| 診断件数 | 100件。正常省略 tag・暗黙 tbody は parse error としない |
| undo | 100操作 / 8 MiB（before+after の UTF-16 bytes）。古い undo だけを解放し notice。現在値を消さない |
| 既存 CSS 境界 | CSS 512 KiB / AST 100,000 / 照合 2,000,000 等は変更しない |

本体の小さい Text fixture で project 14.2 / 22.8 ms を観測した。Worker patch 応答を test-only 700 ms 保留した場合の 703.8 / 711 ms は処理性能ではなく意図的遅延。境界の exact bytes / nodes / depth / matching は adapter 回帰で検証する。
