## Generation/schema decision: binding holds Drive snapshot

A naive HTML/Markdown sourceOwnershipGeneration:number change is not a small typed patch. domain/llm/entity.ts fixed non-PDF branch requires null; libsql llmRepository conversion rejects non-PDF nonnull generation; llmSchema llm_conversion_preparation CHECK requires null when pdfSelectionManifest is null. A new domain branch alone cannot create a valid row, and assigning a fake PDF proof is invalid. No DDL/codec/domain-type widening is proposed.

The minimum no-DDL design keeps the LLM row field sourceOwnershipGeneration=null for HTML/Markdown, preserving its existing PDF-preview semantics. The **Drive ownership generation** is the required positive snapshot already stored in sourceBinding.ownershipGeneration. Typed admission accepts source access through a discriminated local or HTML/Markdown Drive input; Drive branch passes an already-validated binding object with executor/consumer/original/fingerprint/generation, not an unbound number. The stored LLM access.bindingId is the persistent link to that immutable snapshot. Existing repository sourceOrigin/sourceBindingId fields and SourceAccess decoder already represent this link.

regeneration/current.ts must add a narrow typed resolver for a llm-conversion Drive consumer: read the exact access.bindingId in the same Tx; validate consumer kind/id, executor/note/original/fingerprint/cancelGeneration and row source identity; resolve the binding's stored generation; require current driveBackupTransfers.sourceGeneration(noteId) equality. inputConsumer/currentInput must return that resolved number for this Drive-LLM branch so capture can call the existing strict currentDriveSource with a real bound generation. Local/PDF and machine branches remain byte/meaning unchanged. currentLlmSource reuses that same DB resolver and existing currentDriveSource in active and closed checks. It must never pass null as a wildcard or remove the strict comparison for all consumers. This design decision needs Root adoption before implementation; if it cannot meet existing repositories/types, stop and report the exact required type/DDL delta instead of casting or widening storage.
