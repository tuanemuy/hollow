# Media validation fixtures

`media-valid.*` and `media-animated.*` are synthetic sine tones and test-pattern images generated by `generate-media.mjs` using FFmpeg 8.0. They contain no third-party recordings. The generated fixture content is dedicated to the public domain under CC0-1.0. The generator requires an external FFmpeg only when recreating fixtures; production and tests consume the committed files without FFmpeg. Regeneration can change encoder metadata and hashes and requires deliberate fixture review.

The MP3 contains VBR/Xing and ID3v2 Japanese title metadata. M4A uses AAC with fast-start sample tables; Ogg covers Vorbis and Opus. GIF/WebP include animated fixtures. Unit tests derive header-only, truncated and checksum-corrupt inputs from these real writer outputs, and construct bounded WAV/padding cases.

## Inline media
